# Tema 7.2 · Bloque 3 — CSS

> [!abstract] De qué va este tema
> CSS es el estándar de la W3C (tipo MIME `text/css`) para dar estilo a un documento HTML: se aplica mediante reglas `selector { propiedad: valor; }` que se resuelven con la cascada (importancia > especificidad > orden de código). El tema recorre la evolución CSS 1 / 2.x / 3, los preprocesadores y frameworks, los selectores (incluidas pseudo-clases, pseudo-elementos y variables), el posicionamiento, las unidades, y se completa con dos chuletarios de Manz (lite y completo) que listan propiedades y valores.

## Parte I — Teoría (PDF B3-T7.2.1)

### 1. Qué es CSS y su evolución

CSS es un estándar de la **W3C**. Su tipo MIME es **`text/css`** (ver [[Tipo MIME]]).

| Versión | Qué aporta |
|---|---|
| CSS 1 | Selectores básicos (símbolos para referirse a un conjunto de elementos/objetos/nodos del árbol DOM). Modelo caja: todo es una caja. Colores, texto, pseudoclases, fuentes. Cascada: si varias reglas colisionan en un elemento, se aplica la cascada. Más sintaxis CSS, propiedades: `propiedad: valor`. |
| CSS 2.x | Posicionamiento: absoluto, relativo, float, clear, etc., para definir zonas en la página. Tipos de media: `@media print {...}`, `@media screen {...}` (estilos en función del medio). Capas: `z-index` da capacidad de que la página sea 3D (el eje Z crece hacia nosotros). Selectores avanzados. Efectos: sombras, transformaciones. |
| CSS 3 | Media Queries (diseño responsive, adaptativo). Modules: el estándar se ha troceado, cada temática es un módulo y cada uno avanza a su ritmo de forma independiente (selectores, colores, cascada, cajas, media queries, background...). Nuevas técnicas de posicionamiento: FlexBox, Grid y multicolumna. Animaciones, efectos, nuevos selectores. |

```css
box-shadow: valor;
-webkit-box-shadow: valor;  /* prefijo para ese motor de renderizado (WebKit) */
-moz-box-shadow: valor;     /* prefijo para ese motor de renderizado (Mozilla) */
```

> [!note] Diagramas del PDF
> - **Modelo caja** (de fuera adentro): Margin > Border > Padding ("Relleno") > Content.
> - **CSS Grid vs Flexbox**: imagen comparativa (rejilla bidimensional frente a disposición en una dimensión).
> - **Media Queries** (esquema de sintaxis): `@media not|only mediatype and|not|only (media feature) { ... }`. Ejemplo "todos los dispositivos y ancho > 700px": `@media all and (min-width: 700px) { ... }`.

> [!note] Ampliación (conocimiento general, no viene del PDF)
> Los prefijos de fabricante (`-webkit-`, `-moz-`, `-ms-`, `-o-`) corresponden a los motores de renderizado de Chrome/Safari, Firefox, Internet Explorer y Opera, y el chuletario de Manz los muestra en su esquema. Hoy la mayoría de propiedades ya se usan sin prefijo.

### 2. Preprocesadores CSS

Analogía del PDF: en C, antes de compilar hay que pasar el preprocesador, para que resuelva las llamadas a las librerías.

Los preprocesadores son los **superlenguajes de CSS**: traducen a CSS, **transpilan** (source-to-source). En ocasiones se les llama mal «compiladores». Ejemplos: **LESS, SASS, STYLUS, PostCSS**. Aportan variables, bucles, anidamiento, **Mixins** (macros), **Extends**, etc.

```bash
npm install -g less
lessc styles.less styles.css    # lessc es un comando JS
```

Ejemplo SASS (mixin) y su uso:

```scss
@mixin card ($ancho, $alto, $bg, $borde) {
    width: $ancho;
    height: $alto;
    background: $bg;
    border: $borde;
}

.card-1 {
    @include card (300px, 200px, yellow, red 2px solid);
}
.card-2 {
    @include card (400px, 300px, blue, black 1px dotted);
}
```

### 3. Frameworks CSS y concepto DRY

**Frameworks CSS**: Bootstrap, Materialize, Bulma, Foundation, Tailwind CSS, YAML, etc.

**DRY (Don't Repeat Yourself)**: la filosofía es no repetir las propiedades en cada clase, sino **agrupar las propiedades en grupos** y asignar las clases a esos grupos. No usa las clases para definir el diseño sino para referirse al contenido. **No usa preprocesadores.**

```css
#LIGHT_BACKGROUND,
.clase1 ul,
.clase2 h2,
.clase3,
.clase4 li p,
.clase5 .top
{
  background: #FFF
}
```

> [!important] Preprocesador vs DRY
> Un preprocesador (LESS/SASS...) transpila a CSS con variables, mixins y bucles. DRY, en cambio, se resuelve **solo con CSS** agrupando selectores (como el ejemplo de arriba), sin preprocesador.

### 4. Sintaxis, dónde se aplica una regla y at-rules

```css
selector(es) {
    propiedad: valor(es);
    propiedad: valor(es);   /* el último ; es opcional pero es buena práctica */
}
```

#### ¿Dónde se aplica esta regla?

| Forma | Ubicación | Notas |
|---|---|---|
| Externo | `fichero.css` | Enlazado desde el HTML |
| Interno | `fichero.html`, dentro de `<head>` → `<style> ... </style>` | |
| Local (en línea) | `fichero.html`, atributo: `<p style="...">` | Aquí **sobra el selector** al ir directamente sobre la etiqueta |

Eje del esquema: de **−específico** a **+específico** pasando por la cascada (externo → interno → local).

> [!important] Externo vs interno sin definición local
> Si se especifica un color a nivel externo, otro a nivel interno y no hay definición a nivel local, no hay diferencia de importancia. Debería prevalecer el interno, pero no: **coge el último que esté definido**. En la página HTML se enlaza el CSS: si se enlaza **antes** del `<style>`, se aplica el `<style>` interno; si se enlaza **después**, se aplica el formato del CSS externo.

#### at-rules

Son especificaciones muy temáticas.

| at-rule | Función |
|---|---|
| `@charset` | Conjunto de caracteres: UTF-8, ASCII, etc. |
| `@import` | En un CSS, importar otro CSS |
| `@media` | Estilos según el medio / media queries |
| `@font-face` | Instalar tipografías |
| `@page` | Paginación |
| `@layer` | Capa de cascada, para agrupar prioridades |

`@layer`: el orden de declaración de las capas fija su prioridad (a la izquierda, menos prioritaria; a la derecha, más prioritaria).

```css
@layer reset;
@layer typography;
@layer them;
/* equivale a declarar el orden de una vez: */
@layer reset, typography, them;   /* - prioritaria  ...  + prioritaria */

@layer typography {...}
@layer reset {...}
@layer them {...}
```

### 5. Selectores

El **selector universal** es `*`.

| Selector | Qué selecciona |
|---|---|
| `etiqueta {...}` | Todos los elementos de esa etiqueta |
| `#identificador {...}` | El elemento con ese id: `<div id="identificador">` |
| `.clase {...}` | Todos los elementos que pertenezcan a esa clase: `<h1 class="claseh1">` |
| `etiqueta#id {...}` | Elementos de esa etiqueta con ese identificador: `p#especial {}` → `<p id="especial">Párrafo especial.</p>` |
| `etiqueta.clase {...}` | Elementos de ese tipo y de esa clase: `p.clase1` se refiere a los párrafos de la clase `clase1` |
| `etiqueta1, etiqueta2 {...}` | **Agrupamiento**: selectores independientes separados por `,` |
| `etiqueta1 etiqueta2 {...}` | **Contextuales (descendientes)**: aplica a las `etiqueta2` que van dentro de `etiqueta1`. Se lee de derecha a izquierda. Aplica en cualquier nivel. Separados por espacio |
| `etiqueta1 > etiqueta2 {...}` | `etiqueta2` dentro de `etiqueta1` **directamente** (debe ser hijo de `etiqueta1`, no nieto) |
| `a ~ b {...}` | Aplica si `b` es **hermano** (sibling) de `a`, estando `b` a continuación de `a` |
| `a + b {...}` | Aplica si `b` es hermano **directo** de `a`, estando `b` inmediatamente a continuación de `a`, sin más elementos entre medias |
| `E[atr^="algo"] {...}` | Elementos cuyo atributo empieza por "algo" |
| `E[atr$="algo"] {...}` | Elementos cuyo atributo termina en "algo" |
| `E[atr*="algo"] {...}` | Elementos cuyo atributo contiene "algo" |
| `E[atr~="val1 val2 val3"] {...}` | Elementos cuyo atributo es alguno de la lista de valores separados por espacio |
| `E[atr] {...}` | Elementos con el atributo definido |
| `NOT (E[atr])` | Elementos que **no** tengan definido el atributo (usado por desarrolladores para detectar atributos sin definir) |

> [!important] Selectors API (DOM)
> **Selectors** es una API para usar con `Document`:
> - `document.querySelector` devuelve **el primer elemento** que cumpla las condiciones (un nodo).
> - `document.querySelectorAll` devuelve **todos** los elementos que cumplan las condiciones (**una lista de nodos**).

> [!tip] `>` frente a espacio y `+` frente a `~`
> `>` = solo hijo directo; espacio = cualquier nivel. `+` = el hermano inmediatamente siguiente; `~` = cualquier hermano posterior.

### 6. Pseudo-clases y pseudo-elementos

**Pseudo-clase**: manera de definir un **estado**. Sintaxis `selector:pseudoclase {...}`

| Pseudo-clase | Función |
|---|---|
| `:active` `:hover` `:visited` `:invalid` `:empty` `:required` | Listadas en el PDF como ejemplos de estados |
| `:first-child` | Regla para que, dentro de cada `div`, el primer párrafo tenga un formato determinado |
| `:nth-child()` | Para el hijo i-ésimo |
| `:not(selector)` | Negar un selector. `E:not(s)` = elemento que no cumple el selector `s` |
| `:lang()` | Para el lenguaje de un elemento |
| `:root` | Elemento raíz de un árbol que representa el documento; representa el elemento `<html>`. Es idéntico al selector `html`, pero su **especificidad es mayor** |

**Pseudo-elemento**: un trozo de un elemento, una **parte** del elemento. Sintaxis `selector::pseudoelemento {...}` (doble `::`).

| Pseudo-elemento | Función |
|---|---|
| `::after` `::before` `::first-line` | Después / antes / primera línea del elemento |
| `::first-letter` | Para poner la primera letra de un párrafo diferente |

> [!tip] Un `:` o dos
> Pseudo-**clase** = estado = un `:` (`a:hover`). Pseudo-**elemento** = trozo del elemento = dos `::` (`p::first-letter`).

### 7. Custom properties (variables)

Son las variables de CSS.

| | Sintaxis |
|---|---|
| Definición | `--variable: valor;` |
| Uso | `var(--variable)` |

```css
:root {
  --color-destacado: red;
}
div {
  color: var(--color-destacado);
}
```

### 8. Prioridad en cascada y herencia

**Prioridad en cascada**: cuando dos o más reglas coinciden en el mismo elemento.

> [!important] Orden de la cascada: Importance > Specificity > Source Order
> 1. **Importance** (importancia), de más a menos: (1) declaración `!important` del usuario, (2) declaración `!important` del autor, (3) declaración del autor, (4) declaración del usuario, (5) declaración por defecto del navegador.
> 2. Si la importancia es la misma (*Same Importance*) → **Specificity** (especificidad), de más a menos: (1) estilos en línea (*Inline Styles*), (2) IDs, (3) clases, pseudo-clases y atributos, (4) elementos y pseudo-elementos.
> 3. Si la especificidad es la misma (*Same Specificity*) → **Source Order**: la última declaración en el código sobrescribe a todas las demás y es la que se aplica.

Con `!important` se fuerza o cambia este orden:

```css
H1 {
  color: blue !important;
}
```

**Herencia**: mecanismo mediante el cual determinadas propiedades de un elemento padre se transmiten a sus hijos (`font-`, `color`, `text-`, `line-height`, etc.). Ejemplo de **forzar herencia**: `p { background: inherit }`.

> [!note] Ampliación (conocimiento general, no viene del PDF)
> Orden de especificidad de los selectores simples: en línea > `#id` > `.clase`, `[atributo]`, `:pseudo-clase` > `etiqueta`, `::pseudo-elemento`. Esto explica que `:root` (pseudo-clase) tenga mayor especificidad que el selector de etiqueta `html`, como dice el PDF.

### 9. Posicionamiento y visualización

#### Propiedad `position`

| Valor | Comportamiento |
|---|---|
| `static` | Valor por defecto. Orden natural |
| `relative` | Movimiento referido desde su posición *static* (relativo a su posición original) |
| `absolute` | Movimiento referido en base al contenedor padre |
| `fixed` | Movimiento referido en base al documento (permanece en el mismo sitio a pesar del scroll; posición fija relativa a la ventana) |
| `sticky` | Se queda fijo en la pantalla: según vas bajando, el elemento va subiendo hasta que se queda pegado arriba, pero **no desaparece** (relativo a la ventana hasta que con el scroll se queda fijo y pegado a la parte superior) |

`relative`, `absolute` y `fixed` se desplazan con `top`, `bottom`, `left`, `right` y `z-index` (llave del PDF).

> [!tip] Orden de las propiedades de desplazamiento
> El PDF subraya las letras **T R e B o L** (Top, Right, Bottom, Left) como regla mnemotécnica del orden de las cuatro propiedades más `z-index`.

#### Otras propiedades de disposición

| Propiedad | Valores / función |
|---|---|
| `float` | `left` / `right`: ubica un elemento a la izquierda o derecha de su contenedor |
| `clear` | `left` / `right` / `both`: indica si un elemento permite elementos flotantes a sus lados. `left` mueve el elemento debajo del elemento flotante a su izquierda |
| `display` | En CSS3 también existen textos multicolumna. Valores: `none` (no renderiza ni el hueco), `inline` (horizontal), `inline-block`, `block` (vertical), `flex` (nuevo modelo), `grid` (nuevo modelo) |
| `visibility` | `visible`; `hidden` (**sí deja hueco**) |

> [!important] `display: none` vs `visibility: hidden`
> `display: none` no renderiza ni el hueco; `visibility: hidden` oculta el elemento pero **sí deja el hueco**.

### 10. Fuentes, textos, unidades y comentarios

#### Fuentes

`@font-face` sirve para instalar tipografías:

```css
@font-face {
  font-size: 1.5em;
  font-family: "...";
  font-style: normal;
  font-weight: 400;   /* se refiere al grosor */
  src: local (...)
       url(...)
}
```

- **Web Open Font Format (WOFF)**: formato de tipo de letra para páginas web.
- **Tipos de letra escalables**: OpenType (nuevo) y TrueType (antiguo).

#### Textos (propiedades listadas en el PDF)

`letter-spacing`, `line-height`, `word-break`, `text-overflow`, `text-decoration`, `text-indent`, `hyphens`, `text-align`, `text-transform`.

#### Unidades

| Tipo | Unidad | Significado |
|---|---|---|
| Absolutas | `in` | pulgadas |
| | `cm` | centímetros |
| | `pc` | picas |
| | `mm` | milímetros |
| | `pt` | puntos |
| | `px` | píxeles |
| | `Q` | cuarto de mm |
| Relativas | `em` ("M") | tamaño de la fuente del **contenedor padre** |
| | `ex` ("X") | mitad de `em` |
| | `ch` | ancho del cero |
| | `rem` | fuente del root (la etiqueta raíz es HTML) |
| | `%` | porcentaje |
| | `vw` | 1vw = centésima parte del **ancho** de la ventana (cambia con la anchura): `:root {font-size: 2vw}` |
| | `vh` | 1vh = centésima parte del **alto** de la ventana (cambia con el alto) |
| | `vmin` | usa el ratio del lado **más pequeño**: si la altura de la ventana es menor que su anchura, 1vmin equivale a 1vh |
| | `vmax` | usa el ratio del lado **mayor**: 1vmax equivale a 1vw si la ventana es más ancha que alta |

> [!important] `em` vs `rem`
> `em` es relativo a la fuente del contenedor **padre** (corrección del 26/08/2024: no la del navegador). `rem` es relativo a la fuente del **root** (`<html>`).

## Ampliación y conexiones

> [!note] Ampliación (conocimiento general, no viene del PDF)
> Las propiedades `grid-column-gap`, `grid-row-gap` y `grid-gap` del chuletario son los nombres de la primera versión de Grid; hoy se usan `column-gap`, `row-gap` y `gap`. Además, `motion-path`, `motion-offset` y `motion-rotation` fueron sustituidas por `offset-path`, `offset-distance` y `offset-rotate`, y las propiedades de voz (`speak`, `pause`, `cue`, `azimuth`...) corresponden a la antigua CSS Aural/Speech y apenas se usan. Se citan solo para que no desconcierte el nombre al comparar con documentación actual.

**Conexiones con otros conceptos TAI:**
- [[Tipo MIME]] — CSS se sirve con tipo MIME `text/css`.

## 🔑 Resumen ultra-rápido (para repaso)

- CSS = estándar W3C, MIME `text/css`. CSS 1: selectores básicos, modelo caja, cascada, colores, texto, pseudoclases, fuentes. CSS 2.x: posicionamiento, `@media print/screen`, `z-index`, selectores avanzados, sombras/transformaciones. CSS 3: media queries, módulos independientes, FlexBox/Grid/multicolumna, animaciones.
- Modelo caja: Margin > Border > Padding > Content.
- Preprocesadores (LESS, SASS, STYLUS, PostCSS) = superlenguajes que transpilan a CSS (variables, bucles, anidamiento, mixins, extends); `lessc styles.less styles.css`. DRY = agrupar propiedades en grupos de selectores, sin preprocesador. Frameworks: Bootstrap, Materialize, Bulma, Foundation, Tailwind CSS, YAML.
- Una regla se aplica de tres formas: externo (`.css`), interno (`<style>` en `<head>`) y local (`style="..."`, sin selector). Entre externo e interno gana el último definido.
- at-rules: `@charset`, `@import`, `@media`, `@font-face`, `@page`, `@layer` (el orden de las capas fija la prioridad; a la derecha, más prioritaria).
- Selectores: `*`, `etiqueta`, `#id`, `.clase`, `etiqueta#id`, `etiqueta.clase`, `a, b` (agrupamiento), `a b` (descendiente), `a > b` (hijo directo), `a ~ b` (hermano posterior), `a + b` (hermano inmediato), `[atr^=] [atr$=] [atr*=] [atr~=] [atr]`. `querySelector` = un nodo; `querySelectorAll` = lista de nodos.
- Pseudo-clase = estado, un `:`; pseudo-elemento = parte del elemento, `::`. `:root` = `<html>` con mayor especificidad.
- Variables: `--nombre: valor;` y `var(--nombre)`, normalmente en `:root`.
- Cascada: Importance > Specificity > Source Order. Importancia: user `!important` > author `!important` > author > user > navegador. Especificidad: inline > IDs > clases/pseudoclases/atributos > elementos/pseudoelementos. `!important` fuerza el orden; `inherit` fuerza la herencia.
- `position`: `static` (por defecto), `relative` (desde su posición), `absolute` (respecto al contenedor padre), `fixed` (respecto al documento/ventana), `sticky` (se pega arriba sin desaparecer). `float`, `clear`, `display` (`none` no deja hueco; `inline`, `inline-block`, `block`, `flex`, `grid`), `visibility: hidden` sí deja hueco.
- Fuentes: `@font-face`, WOFF (web), OpenType (nuevo) / TrueType (antiguo). Unidades: absolutas (`in cm pc mm pt px Q`) y relativas (`em` = fuente del padre, `ex` = mitad de em, `ch` = ancho del cero, `rem` = fuente del root, `%`, `vw`, `vh`, `vmin` = lado menor, `vmax` = lado mayor).
- Comentarios: HTML `<!-- -->`, CSS `/* */`.
- Cheatsheet lite y completo de Manz: sintaxis, colores (keyword, hex, RGB, HSL, alfa), fondos, tablas, fuentes, texto, bordes, listas, cursores, columnas, degradados, sombras, transiciones, animaciones y `@keyframes`, transformaciones 2D/3D, filtros, `@media`, `@page`, `@supports`, máscaras, formas, scroll snap, Flexbox, Grid y alineación (listados completos en las Partes II y III).
