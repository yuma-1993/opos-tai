UML define cuatro **mecanismos de extensión** para añadir semántica propia a la notación estándar sin modificar el metamodelo:

- **Estereotipos**: añaden o modifican la semántica de un elemento, dándole especificidad (ej. `<<UI>>` indica que una clase es de tipo interfaz de usuario).
- **Restricciones**: una regla que debe cumplirse sobre el elemento (ej. `{ordered}`).
- **Valores etiquetados**: un metadato asociado al elemento (ej. `{procesadores=3}`).
- **Perfiles**: un conjunto de estereotipos, restricciones y valores etiquetados agrupados en torno a un tema o plataforma concreta (ej. el perfil Java EJB, ver [[Diagrama de perfil (UML)]]).
