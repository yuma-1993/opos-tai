**X →→ Y** ("X multidetermina a Y"): a cada valor de X le corresponde un conjunto de valores de Y (independiente de otros atributos). Es una generalización de la [[Dependencia funcional|DF]] (la DF es un caso particular donde ese conjunto tiene siempre 1 elemento). Se usa para detectar problemas de 4FN (ver [[Formas normales (1FN a 6FN)]]).

> [!example]
> `Clases(materia, profesor, bibliografia)` → una materia puede tener varios profesores y varias referencias bibliográficas, sin relación entre ambos conjuntos.
