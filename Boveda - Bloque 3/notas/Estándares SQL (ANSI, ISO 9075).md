Sucesión de estándares que ha ido definiendo qué debe soportar un SGBD para llamarse compatible con SQL. Tabla de hitos principales:

| Estándar | Novedad principal |
|---|---|
| ANSI:86 | Primer estándar |
| ANSI-92 | Revisión grande. Es la más conocida |
| ISO 9075 SQL:1999 | SQL 3. Introduce triggers |
| ISO 9075 SQL:2003 | Introduce el objeto SEQUENCE |
| ISO 9075 SQL:2006 | XML nativo |
| ISO 9075 SQL:2008 | Sentencia TRUNCATE |
| ISO 9075 SQL:2016 | Compatibilidad JSON |

A partir de SQL:1999 el estándar pasa a publicarse como norma ISO/IEC 9075, no solo ANSI — de ahí que las versiones posteriores se citen con ambos nombres.
