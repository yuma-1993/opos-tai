Patrón de **arquitectura** que organiza el sistema en capas apiladas, al estilo del modelo OSI: una capa N solo se comunica con la capa inmediatamente superior (N+1) y la inmediatamente inferior (N-1), nunca salta capas. Es la base organizativa típica de las aplicaciones en capas (presentación, negocio, persistencia...).
