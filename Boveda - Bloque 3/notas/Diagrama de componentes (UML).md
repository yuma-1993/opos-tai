El **diagrama de componentes** modela un sistema como un conjunto de **componentes**: unidades de alto nivel que agrupan varias clases y ofrecen un servicio a otros componentes, pensadas para ser **reutilizadas**. Un componente rara vez es 100% autónomo — normalmente necesita consumir servicios de otro componente.

La notación distingue tres elementos: el **círculo** representa la **interfaz proporcionada** (*provided* — lo que el componente ofrece, lo que se puede usar de él); el **semicírculo** representa la **interfaz requerida** (*required* — de qué depende el componente, qué necesita de otro) y se usa para conectar unos componentes con otros; y el **cuadrado** representa el **puerto**.
