**CITAD** es el acrónimo de las cinco dimensiones de seguridad que usa el Esquema Nacional de Seguridad (ENS) para valorar el impacto de un incidente: **C**onfidencialidad, **I**ntegridad, **T**razabilidad, **A**utenticidad y **D**isponibilidad.

Para cada dimensión se determina un nivel (BAJO, MEDIO o ALTO) en función de la gravedad de las consecuencias de un incidente sobre las funciones, activos o individuos afectados — el mayor nivel encontrado para cada función, activo o individuo. La **categoría de seguridad** del sistema (BÁSICA, MEDIA o ALTA) se fija según el nivel más alto alcanzado en cualquiera de las cinco dimensiones: BÁSICA si alguna llega a BAJO sin superarlo, MEDIA si alguna llega a MEDIO sin superarlo, ALTA si alguna llega a ALTO.
