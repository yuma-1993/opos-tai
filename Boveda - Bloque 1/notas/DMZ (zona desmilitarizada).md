Una **DMZ** (zona desmilitarizada) es un segmento de red aislado entre la red interna y la red externa (Internet u otra red no confiable), con cortafuegos a ambos lados, donde se colocan los servicios que necesitan ser accesibles desde fuera sin exponer directamente la red interna.

En la [[Red SARA]], el **Área de Conexión (AC)** que instala el Proveedor de Acceso (PAS) para dar entrada a un organismo se describe precisamente como una DMZ: agrupa ahí el DNS, Proxy, Switch, SMTP, IDS, IPS, Firewall y Proxy Inverso, es decir, los elementos de control de tráfico entre el organismo y la red.
