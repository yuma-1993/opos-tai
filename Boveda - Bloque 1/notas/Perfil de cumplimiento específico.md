Un **perfil de cumplimiento específico** es el conjunto de medidas de seguridad del Esquema Nacional de Seguridad (ENS) que, tras el preceptivo análisis de riesgos, resultan de aplicación a una entidad o sector de actividad concreto, para una determinada categoría de seguridad. El **CCN** valida y publica estos perfiles.

Sirven para agilizar la implantación del ENS en sectores o tipos de entidad con características comunes, en vez de que cada organización tenga que partir de cero de las 73 medidas generales. Un ejemplo es la guía [[CCN-STIC]]-883B, el perfil de cumplimiento específico para ayuntamientos de menos de 20.000 habitantes.
